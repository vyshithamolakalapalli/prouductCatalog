# Product Catalog - ASP.NET MVC

## Experiment
Create Product Catalog Application using ASP.NET MVC Architecture (Controllers, Models, Views, Routing).

## Features
- Product catalog listing
- Add new product
- Product details
- MVC Controller, Model and Views
- Default routing

## Technologies
- ASP.NET MVC 5
- C#
- .NET Framework 4.8
- Visual Studio 2022

## Run
Open the project in Visual Studio 2022, restore the required ASP.NET MVC/NuGet packages, then run the application.

Default route:
`/Product/Index`
